# تطوير وصيانة عزت السراء — Bluetooth Chat

تطبيق Android للمحادثة النصية بدون إنترنت، باستخدام Bluetooth Classic بين أجهزة مقترنة.

## التشغيل
1. افتح المشروع في Android Studio.
2. انتظر مزامنة Gradle.
3. ثبّت التطبيق على جهازين Android.
4. اقترن الجهازان من إعدادات Bluetooth.
5. افتح التطبيق على الجهازين واضغط اسم الجهاز الآخر للاتصال.
6. أرسل الرسائل بدون إنترنت.

## ملاحظات
- النسخة الحالية MVP للمحادثة النصية.
- لا تعتمد على خادم أو بيانات جوال أو Wi‑Fi.
- يمكن تطويرها لاحقاً لإضافة الصور، الملفات، الرسائل الصوتية، الحالات، الإشعارات، وتشفير طرفي.
- Android قد يطلب صلاحيات Bluetooth عند أول تشغيل.
